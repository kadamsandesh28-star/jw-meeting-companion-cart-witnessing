# Cart Witnessing v8

- Fixed weekly date alignment for saved Cart Witnessing schedules.
- If an older saved schedule has all entries in a previous whole week and the selected `weekOf` is a later Saturday, the app migrates those entries and day captains forward by the week difference.
- If entries already belong to the selected week, they are left unchanged.
- Weekly view and exports sort entries by actual start time ascending.
- Preserves the v7 polished PDF layout and original cart illustration.
